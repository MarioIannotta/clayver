# Code of Conduct

Clayver follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to everyone taking part in the project: in issues, pull requests,
discussions, reviews and any other project space, and when representing the
project in public.

In short: be welcoming, be respectful, accept constructive feedback gracefully,
and focus on what is best for the community. Harassment, insults, personal or
political attacks, and publishing others' private information are not
acceptable.
